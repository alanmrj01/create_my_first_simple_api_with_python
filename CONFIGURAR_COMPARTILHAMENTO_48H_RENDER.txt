API CENTRAL — COMPARTILHAMENTO TEMPORÁRIO POR 48 HORAS

AUTENTICAÇÃO DA PUBLICAÇÃO

A API aceita a credencial principal já configurada em API_SECRET_TOKEN. Assim,
o ERP 44.1 funciona sem exigir uma segunda variável local.

REPORT_UPLOAD_TOKEN permanece OPCIONAL. Quando configurado, ele cria uma
credencial dedicada adicional para publicação e revogação; API_SECRET_TOKEN
continua válido para preservar as instalações existentes.

O destinatário do relatório não informa credenciais. O link contém apenas um
token público aleatório e assinado, expira exatamente após 48 horas e pode ser
revogado pelo ERP.

SEGREDOS EXCLUSIVOS DO RENDER

REPORT_SHARE_SIGNING_SECRET=<segredo longo, recomendado>
REPORT_SHARE_STORAGE_ENDPOINT_URL=<endpoint do bucket privado>
REPORT_SHARE_STORAGE_BUCKET=<nome do bucket>
REPORT_SHARE_STORAGE_ACCESS_KEY_ID=<chave do bucket>
REPORT_SHARE_STORAGE_SECRET_ACCESS_KEY=<segredo do bucket>
REPORT_SHARE_STORAGE_REGION=auto
REPORT_SHARE_STORAGE_BACKEND=r2
REPORT_SHARE_PUBLIC_BASE_URL=https://conversor-siff.onrender.com

Esses valores nunca devem ser copiados para o ERP. Caso
REPORT_SHARE_SIGNING_SECRET esteja ausente, a API mantém compatibilidade usando
API_SECRET_TOKEN para assinar os links, mas o segredo dedicado é recomendado.

REPORT_UPLOAD_TOKEN OPCIONAL

REPORT_UPLOAD_TOKEN=<token dedicado para publicar/revogar>

Somente quando esse token opcional for usado, o mesmo valor poderá ser colocado
no ERP como REPORT_SHARE_UPLOAD_TOKEN.
